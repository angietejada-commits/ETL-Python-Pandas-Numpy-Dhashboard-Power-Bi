# ETL-Python-Pandas-Numpy-Dhashboard-Power-Bi
Proceso ETL de limpieza y transformación de datos con Python, Pandas y Numpy, utilizando G Colab y Apoyo IA Gemini con diferentes LLM, seguido de análisis y visualización de resultados.
Proceso ETL con Python, pandas y NumPy

## 📌 Descripción

Proyecto de análisis y transformación de datos desarrollado como parte de mi formación en Business Intelligence y Data Analytics.

El proyecto consiste en realizar un proceso ETL (Extract, Transform, Load) sobre un conjunto de datos, utilizando Python y las librerías pandas y NumPy en Google Colab.

El objetivo principal fue transformar datos inicialmente sin depurar en una base estructurada y preparada para análisis y visualización.

## 🎯 Objetivos

- Extraer y revisar los datos originales.
- Identificar problemas de calidad de datos.
- Realizar procesos de limpieza y transformación.
- Gestionar valores nulos y registros inconsistentes.
- Estandarizar y preparar las variables para el análisis.
- Generar una base de datos final limpia.
- Analizar los resultados obtenidos.
- Construir visualizaciones a partir de los datos transformados.

## 🛠️ Herramientas utilizadas

- Python
- pandas
- NumPy
- Google Colab
- IA generativa como herramienta de apoyo para programación y resolución de problemas
- Power BI / herramientas de visualización

## 🔄 Proceso ETL

### 1. Extract — Extracción

Se cargaron los datos originales en Google Colab para realizar una primera exploración de su estructura y calidad.

### 2. Transform — Transformación

Se realizaron diferentes procesos de limpieza y transformación, incluyendo:

- Identificación y tratamiento de valores nulos.
- Revisión de tipos de datos.
- Eliminación o tratamiento de registros inconsistentes.
- Estandarización de información.
- Transformación de variables.
- Validación de los resultados.

### 3. Load — Carga

Después del proceso de transformación se generó un archivo con los datos limpios, preparado para continuar con las etapas de análisis y visualización.

## 🤖 Uso de inteligencia artificial

Durante el desarrollo del proyecto se utilizó inteligencia artificial generativa como herramienta de apoyo para la construcción, explicación y ajuste del código Python.

La IA fue utilizada mediante instrucciones específicas para resolver tareas de transformación de datos. Posteriormente, los resultados fueron revisados y validados para asegurar que las transformaciones realizadas correspondieran a las necesidades del proyecto.

Este proceso permitió integrar conocimientos de análisis de datos, programación y utilización responsable de herramientas de IA.

## 📊 Análisis y visualización

A partir de la base de datos limpia se desarrollaron visualizaciones para analizar los principales resultados obtenidos durante el proceso.

Las visualizaciones permiten identificar patrones, comportamientos y relaciones relevantes presentes en los datos.
